# Add Drizzle to an existing D1 project

<Prerequisites>
  - **Cloudflare D1** - [read here](https://developers.cloudflare.com/d1/)
  - **wrangler** - Cloudflare Developer Platform command-line interface - [read here](https://developers.cloudflare.com/workers/wrangler)
</Prerequisites>

For existing Cloudflare projects, the recommended D1 path is still `drizzle-orm/d1-object`.

<Callout type="warning" title="Legacy D1 bindings">
If your existing app uses a D1 database binding like `env.DB`, the `drizzle-orm/d1` driver and `driver: "d1-http"` configuration remain available as a legacy path. Do not use them for new D1 projects.
</Callout>

#### Step 1 - Install packages

<Npm>
drizzle-orm
-D drizzle-kit
</Npm>

#### Step 2 - Add or keep your Drizzle schema

Use SQLite schema definitions.

```typescript copy filename="src/schema.ts"
import { sql } from 'drizzle-orm';
import { integer, sqliteTable, text } from 'drizzle-orm/sqlite-core';

export const users = sqliteTable('users', {
  id: integer('id').primaryKey({ autoIncrement: true }),
  name: text('name').notNull(),
  email: text('email').notNull().unique(),
  createdAt: text('created_at').notNull().default(sql`CURRENT_TIMESTAMP`),
});
```

Drizzle Kit does not `pull` schema for `driver: "d1-object"`. If you are moving from a legacy D1 binding database, keep using the legacy flow for that database until you have ported the schema and data.

#### Step 3 - Configure D1

Replace the old `[[d1_databases]]` binding for new `d1-object` code with an export.

```toml copy filename="wrangler.toml"
name = "drizzle-d1-app"
main = "src/index.ts"
compatibility_date = "2026-06-13"

[exports.AppDatabase]
type = "durable_object"
storage = "sqlite"
```

#### Step 4 - Replace `env.DB` usage with object routing

Old D1 binding code created Drizzle from a Worker binding:

```typescript copy
import { drizzle } from 'drizzle-orm/d1';

const db = drizzle(env.DB);
```

New D1 code creates Drizzle inside the database class:

```typescript copy filename="src/index.ts"
import { DrizzleD1Object, drizzle } from 'drizzle-orm/d1-object';
import { eq } from 'drizzle-orm';
import { users } from './schema';
import * as schema from './schema';

export interface Env {
  AppDatabase: DurableObjectNamespace<AppDatabase>;
}

export class AppDatabase extends DrizzleD1Object<Env> {
  db = drizzle(this.ctx, { schema });

  async findUser(email: string, bookmark: string | null = null) {
    await this.db.d1.waitForBookmark(bookmark);

    return {
      user: this.db.select().from(users).where(eq(users.email, email)).get(),
      bookmark: await this.db.d1.getCurrentBookmark(),
    };
  }

  async createUser(input: typeof users.$inferInsert) {
    const user = this.db.insert(users).values(input).returning().get();

    return {
      user,
      bookmark: await this.db.d1.getCurrentBookmark(),
    };
  }
}

export default {
  async fetch(request, env): Promise<Response> {
    const url = new URL(request.url);
    const objectName = `tenant:${url.hostname}`;

    if (request.method === 'POST') {
      const db = env.AppDatabase.getByName(objectName, {
        routingMode: 'primary-only',
      });
      const result = await db.createUser(await request.json());

      return Response.json(result.user, {
        status: 201,
        headers: { 'x-d1-bookmark': result.bookmark },
      });
    }

    const db = env.AppDatabase.getByName(objectName);
    const result = await db.findUser(
      url.searchParams.get('email') ?? '',
      request.headers.get('x-d1-bookmark'),
    );

    return Response.json(result.user, {
      headers: { 'x-d1-bookmark': result.bookmark },
    });
  },
} satisfies ExportedHandler<Env>;
```

#### Step 5 - Configure Drizzle Kit

Use `driver: "d1-object"` for generated bundled migrations.

```typescript copy filename="drizzle.config.ts"
import { defineConfig } from 'drizzle-kit';

export default defineConfig({
  out: './drizzle',
  schema: './src/schema.ts',
  dialect: 'sqlite',
  driver: 'd1-object',
});
```

Generate migrations:

```bash copy
npx drizzle-kit generate
```

#### Step 6 - Apply migrations

```typescript copy filename="src/index.ts"
import migrations from '../drizzle/migrations';

export class AppDatabase extends DrizzleD1Object<Env> {
  db = drizzle(this.ctx, { schema });

  applyMigrations() {
    return this.applyDrizzleMigrations(migrations);
  }
}
```

Call the migration method through a primary-only stub:

```typescript copy
const db = env.AppDatabase.getByName('tenant:example.com', {
  routingMode: 'primary-only',
});

await db.applyMigrations();
```
