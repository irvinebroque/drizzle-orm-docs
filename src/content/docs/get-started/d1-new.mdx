# Get Started with Drizzle and D1

<Prerequisites>
  - **Cloudflare D1** - [read here](https://developers.cloudflare.com/d1/)
  - **wrangler** - Cloudflare Developer Platform command-line interface - [read here](https://developers.cloudflare.com/workers/wrangler)
</Prerequisites>

Use `drizzle-orm/d1-object` for new Cloudflare D1 applications.

#### Step 1 - Install required packages

<Npm>
drizzle-orm
-D drizzle-kit
</Npm>

#### Step 2 - Create a schema

```typescript copy filename="src/schema.ts"
import { sql } from 'drizzle-orm';
import { integer, sqliteTable, text } from 'drizzle-orm/sqlite-core';

export const users = sqliteTable('users', {
  id: integer('id').primaryKey({ autoIncrement: true }),
  name: text('name').notNull(),
  email: text('email').notNull().unique(),
  createdAt: text('created_at').notNull().default(sql`CURRENT_TIMESTAMP`),
});
```

#### Step 4 - Put Drizzle in the database object

The Worker routes each request to a database object. Create Drizzle with `drizzle(this.ctx, { schema })` inside that object, then wrap the object stub with `createD1ObjectSession()` in the Worker.

```typescript copy filename="src/index.ts"
import { createD1ObjectSession, DrizzleD1Object, drizzle } from 'drizzle-orm/d1-object';
import { eq } from 'drizzle-orm';
import { users } from './schema';
import * as schema from './schema';

type CreateUserInput = {
  name: string;
  email: string;
};

export interface Env {
  AppDatabase: DurableObjectNamespace<AppDatabase>;
}

// This class is the database. Drizzle runs here, inside the Durable Object.
export class AppDatabase extends DrizzleD1Object<Env> {
  db = drizzle(this.ctx, { schema });

  async createUser(input: CreateUserInput) {
    return this.db.insert(users).values(input).returning().get();
  }

  async getUser(email: string) {
    return this.db.select().from(users).where(eq(users.email, email)).get();
  }
}

export default {
  async fetch(request, env): Promise<Response> {
    const url = new URL(request.url);
    const objectName = `tenant:${url.hostname}`;

    if (request.method === 'POST' && url.pathname === '/users') {
      // Get the database object for this tenant and call methods on it.
      const db = createD1ObjectSession<AppDatabase>(
        env.AppDatabase.getByName(objectName, {
          routingMode: 'primary-only',
        }),
      );
      const input = (await request.json()) as CreateUserInput;
      const user = await db.client.createUser(input);

      return Response.json(user, { status: 201 });
    }

    if (request.method === 'GET' && url.pathname === '/users') {
      // Default routing can use a nearby read replica.
      const db = createD1ObjectSession<AppDatabase>(env.AppDatabase.getByName(objectName));
      const user = await db.client.getUser(url.searchParams.get('email') ?? '');

      return Response.json(user);
    }

    return new Response('Not found', { status: 404 });
  },
} satisfies ExportedHandler<Env>;
```

#### Step 6 - Configure Drizzle Kit

```typescript copy filename="drizzle.config.ts"
import { defineConfig } from 'drizzle-kit';

export default defineConfig({
  out: './drizzle',
  schema: './src/schema.ts',
  dialect: 'sqlite',
  driver: 'd1-object',
});
```

Generate bundled migrations:

```bash copy
npx drizzle-kit generate
```

#### Step 7 - Apply migrations

Run generated migrations through your D1 class.

```typescript copy filename="src/index.ts"
import migrations from '../drizzle/migrations';

export class AppDatabase extends DrizzleD1Object<Env> {
  db = drizzle(this.ctx, { schema });

  applyMigrations() {
    return this.applyDrizzleMigrations(migrations);
  }
}
```

Call the migration method through a primary-only stub:

```typescript copy
const db = env.AppDatabase.getByName('tenant:example.com', {
  routingMode: 'primary-only',
});

await db.applyMigrations();
```
