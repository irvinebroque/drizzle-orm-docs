# Get Started with Drizzle and D1

<Prerequisites>
  - **Cloudflare D1** - SQLite databases backed by Durable Objects - [read here](https://developers.cloudflare.com/d1/)
  - **Cloudflare Durable Objects** - stateful compute and SQLite storage - [read here](https://developers.cloudflare.com/durable-objects/)
  - **wrangler** - Cloudflare Developer Platform command-line interface - [read here](https://developers.cloudflare.com/workers/wrangler)
</Prerequisites>

Start new Cloudflare D1 applications with `drizzle-orm/d1-object`. Your Worker routes requests to the right Durable Object, and Drizzle runs inside the object that owns the SQLite database.

<Callout type="info" title="Recommended path">
Use this guide for new D1 applications. The older `drizzle-orm/d1` database binding driver and `driver: "d1-http"` Drizzle Kit configuration are legacy paths for existing D1 binding projects.
</Callout>

#### Step 1 - Install required packages

<Npm>
drizzle-orm
-D drizzle-kit wrangler
</Npm>

#### Step 2 - Create a schema

```typescript copy filename="src/schema.ts"
import { sql } from 'drizzle-orm';
import { integer, sqliteTable, text } from 'drizzle-orm/sqlite-core';

export const users = sqliteTable('users', {
  id: integer('id').primaryKey({ autoIncrement: true }),
  name: text('name').notNull(),
  email: text('email').notNull().unique(),
  createdAt: text('created_at').notNull().default(sql`CURRENT_TIMESTAMP`),
});
```

#### Step 3 - Configure a SQLite-backed Durable Object

```toml copy filename="wrangler.toml"
name = "drizzle-d1-app"
main = "src/index.ts"
compatibility_date = "2026-06-13"

[exports.AppDatabase]
type = "durable_object"
storage = "sqlite"
```

#### Step 4 - Connect Drizzle inside the object

Create the Drizzle client from `this.ctx` inside the Durable Object. Route writes through a primary-only stub and pass bookmarks from write responses to later reads when the client needs read-your-writes consistency.

```typescript copy filename="src/index.ts"
import { DrizzleD1Object, drizzle } from 'drizzle-orm/d1-object';
import { eq } from 'drizzle-orm';
import { users } from './schema';
import * as schema from './schema';

type CreateUserInput = {
  name: string;
  email: string;
};

export interface Env {
  AppDatabase: DurableObjectNamespace<AppDatabase>;
}

export class AppDatabase extends DrizzleD1Object<Env> {
  db = drizzle(this.ctx, { schema });

  async createUser(input: CreateUserInput) {
    const user = this.db.insert(users).values(input).returning().get();

    return {
      user,
      bookmark: await this.db.d1.getCurrentBookmark(),
    };
  }

  async getUser(email: string, bookmark: string | null = null) {
    await this.db.d1.waitForBookmark(bookmark);

    return {
      user: this.db.select().from(users).where(eq(users.email, email)).get(),
      bookmark: await this.db.d1.getCurrentBookmark(),
    };
  }
}

export default {
  async fetch(request, env): Promise<Response> {
    const url = new URL(request.url);
    const objectName = `tenant:${url.hostname}`;

    if (request.method === 'POST' && url.pathname === '/users') {
      const db = env.AppDatabase.getByName(objectName, {
        routingMode: 'primary-only',
      });
      const input = (await request.json()) as CreateUserInput;
      const result = await db.createUser(input);

      return Response.json(result.user, {
        status: 201,
        headers: { 'x-d1-bookmark': result.bookmark },
      });
    }

    if (request.method === 'GET' && url.pathname === '/users') {
      const db = env.AppDatabase.getByName(objectName);
      const result = await db.getUser(
        url.searchParams.get('email') ?? '',
        request.headers.get('x-d1-bookmark'),
      );

      return Response.json(result.user, {
        headers: { 'x-d1-bookmark': result.bookmark },
      });
    }

    return new Response('Not found', { status: 404 });
  },
} satisfies ExportedHandler<Env>;
```

#### Step 6 - Configure Drizzle Kit

```typescript copy filename="drizzle.config.ts"
import { defineConfig } from 'drizzle-kit';

export default defineConfig({
  out: './drizzle',
  schema: './src/schema.ts',
  dialect: 'sqlite',
  driver: 'd1-object',
});
```

Generate bundled migrations:

```bash copy
npx drizzle-kit generate
```

#### Step 7 - Apply migrations from the object

SQL migrations for D1 application objects run inside the Durable Object on the primary. Add an object method that calls `applyDrizzleMigrations()`.

```typescript copy filename="src/index.ts"
import migrations from '../drizzle/migrations';

export class AppDatabase extends DrizzleD1Object<Env> {
  db = drizzle(this.ctx, { schema });

  applyMigrations() {
    return this.applyDrizzleMigrations(migrations);
  }
}
```

Call the migration method through a primary-only stub:

```typescript copy
const db = env.AppDatabase.getByName('tenant:example.com', {
  routingMode: 'primary-only',
});

await db.applyMigrations();
```
