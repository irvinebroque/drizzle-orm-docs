# Add Drizzle to an existing SQLite Durable Objects project

<Prerequisites>
  - **Cloudflare SQLite Durable Objects** - SQLite database embedded within a Durable Object - [read here](https://developers.cloudflare.com/durable-objects/api/sqlite-storage-api/)
  - **wrangler** - Cloudflare Developer Platform command-line interface - [read here](https://developers.cloudflare.com/workers/wrangler)
</Prerequisites>

<Callout type="warning" title="Legacy low-level path">
This page is for existing applications that already use SQLite Durable Objects directly. For new Cloudflare D1 applications, use [Get Started with Drizzle and D1](/docs/get-started/d1-new) and the `drizzle-orm/d1-object` driver.
</Callout>

#### Step 1 - Install packages

<Npm>
drizzle-orm
-D drizzle-kit wrangler
</Npm>

#### Step 2 - Keep your SQLite Durable Object binding

Existing low-level Durable Objects applications continue to use a Durable Object binding and class migration.

```toml copy filename="wrangler.toml"
name = "sqlite-durable-objects"
main = "src/index.ts"
compatibility_date = "2024-11-12"
compatibility_flags = [ "nodejs_compat" ]

[[durable_objects.bindings]]
name = "MY_DURABLE_OBJECT"
class_name = "MyDurableObject"

[[migrations]]
tag = "v1"
new_sqlite_classes = ["MyDurableObject"]

[[rules]]
type = "Text"
globs = ["**/*.sql"]
fallthrough = true
```

#### Step 3 - Create Drizzle from `ctx.storage`

```typescript copy filename="src/index.ts"
import { drizzle, type DrizzleSqliteDODatabase } from 'drizzle-orm/durable-sqlite';
import { DurableObject } from 'cloudflare:workers';
import { users } from './schema';

export class MyDurableObject extends DurableObject {
  db: DrizzleSqliteDODatabase;

  constructor(ctx: DurableObjectState, env: Env) {
    super(ctx, env);
    this.db = drizzle(ctx.storage, { logger: false });
  }

  async createUser(user: typeof users.$inferInsert) {
    return this.db.insert(users).values(user).returning().get();
  }

  async listUsers() {
    return this.db.select().from(users);
  }
}
```

#### Step 4 - Configure Drizzle Kit

```typescript copy filename="drizzle.config.ts"
import { defineConfig } from 'drizzle-kit';

export default defineConfig({
  out: './drizzle',
  schema: './src/schema.ts',
  dialect: 'sqlite',
  driver: 'durable-sqlite',
});
```

Generate bundled migrations:

```bash copy
npx drizzle-kit generate
```

Apply them from object code:

```typescript copy filename="src/index.ts"
import { migrate } from 'drizzle-orm/durable-sqlite/migrator';
import migrations from '../drizzle/migrations';

export class MyDurableObject extends DurableObject {
  db: DrizzleSqliteDODatabase;

  async migrate() {
    migrate(this.db, migrations);
  }
}
```

Drizzle Kit cannot directly `push`, `pull`, `migrate`, or open `studio` against a SQLite Durable Object.
