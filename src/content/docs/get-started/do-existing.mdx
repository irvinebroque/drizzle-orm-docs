# Add Drizzle to an existing SQLite Durable Objects project

<Prerequisites>
  - **Cloudflare Durable Objects** - [read here](https://developers.cloudflare.com/durable-objects/)
  - **wrangler** - Cloudflare Developer Platform command-line interface - [read here](https://developers.cloudflare.com/workers/wrangler)
</Prerequisites>

For existing SQL-backed Durable Objects projects, prefer `drizzle-orm/d1-object`.

<Callout type="info" title="Recommended adapter">
Use `drizzle-orm/d1-object` for the durable object database path. Keep `drizzle-orm/durable-sqlite` only for existing low-level integrations that cannot move yet.
</Callout>

#### Step 1 - Install packages

<Npm>
drizzle-orm
-D drizzle-kit
</Npm>

#### Step 2 - Configure the Durable Object export

```jsonc copy filename="wrangler.jsonc"
{
  "$schema": "./node_modules/wrangler/config-schema.json",
  "name": "drizzle-durable-object-app",
  "main": "src/index.ts",
  "compatibility_date": "2026-06-13",
  "exports": {
    "NotesDatabase": {
      "type": "durable_object",
      "storage": "sqlite"
    }
  }
}
```

#### Step 3 - Create Drizzle from the Durable Object context

```typescript copy filename="src/index.ts"
import { desc } from 'drizzle-orm';
import { DrizzleD1Object, drizzle } from 'drizzle-orm/d1-object';
import { notes } from './schema';
import * as schema from './schema';

export interface Env {
  NotesDatabase: DurableObjectNamespace<NotesDatabase>;
}

export class NotesDatabase extends DrizzleD1Object<Env> {
  db = drizzle(this.ctx, { schema });

  async createNote(body: string) {
    const note = this.db.insert(notes).values({ body }).returning().get();

    return {
      note,
      bookmark: await this.db.d1.getCurrentBookmark(),
    };
  }

  async listNotes(bookmark: string | null = null) {
    await this.db.d1.waitForBookmark(bookmark);

    return {
      notes: this.db.select().from(notes).orderBy(desc(notes.id)).limit(20).all(),
      bookmark: await this.db.d1.getCurrentBookmark(),
    };
  }
}
```

Route known writes through a primary-only stub:

```typescript copy
const db = env.NotesDatabase.getByName('notes:default', {
  routingMode: 'primary-only',
});

await db.createNote('hello');
```

#### Step 4 - Configure Drizzle Kit

```typescript copy filename="drizzle.config.ts"
import { defineConfig } from 'drizzle-kit';

export default defineConfig({
  out: './drizzle',
  schema: './src/schema.ts',
  dialect: 'sqlite',
  driver: 'd1-object',
});
```

Generate bundled migrations:

```bash copy
npx drizzle-kit generate
```

Apply them from an object method:

```typescript copy filename="src/index.ts"
import migrations from '../drizzle/migrations';

export class NotesDatabase extends DrizzleD1Object<Env> {
  db = drizzle(this.ctx, { schema });

  applyMigrations() {
    return this.applyDrizzleMigrations(migrations);
  }
}
```

#### Older `durable-sqlite` driver

Existing applications that already use `drizzle-orm/durable-sqlite` can keep that path while migrating.

```typescript copy filename="src/index.ts"
import { drizzle, type DrizzleSqliteDODatabase } from 'drizzle-orm/durable-sqlite';
import { migrate } from 'drizzle-orm/durable-sqlite/migrator';
import { DurableObject } from 'cloudflare:workers';
import migrations from '../drizzle/migrations';
import { notes } from './schema';

export class LegacyNotesDatabase extends DurableObject {
  db: DrizzleSqliteDODatabase;

  constructor(ctx: DurableObjectState, env: Env) {
    super(ctx, env);
    this.db = drizzle(ctx.storage, { logger: false });
  }

  async listNotes() {
    return this.db.select().from(notes);
  }

  async migrate() {
    migrate(this.db, migrations);
  }
}
```

```typescript copy filename="drizzle.config.ts"
import { defineConfig } from 'drizzle-kit';

export default defineConfig({
  out: './drizzle',
  schema: './src/schema.ts',
  dialect: 'sqlite',
  driver: 'durable-sqlite',
});
```

Drizzle Kit cannot directly `push`, `pull`, `migrate`, or open `studio` against this driver. Generate migrations and apply them through object code.
