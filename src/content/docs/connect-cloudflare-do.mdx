# Drizzle \<\> Cloudflare Durable Objects

<Prerequisites>
- Database [connection basics](/docs/connect-overview) with Drizzle
- Cloudflare Durable Objects - [read here](https://developers.cloudflare.com/durable-objects/)
- Cloudflare SQLite storage - [read here](https://developers.cloudflare.com/durable-objects/api/sqlite-storage-api/)
</Prerequisites>

Use Drizzle with Cloudflare Durable Objects through the `drizzle-orm/d1-object` adapter. This is the recommended Durable Objects path for SQL-backed applications: the Durable Object owns the SQLite database, Drizzle runs inside the object, and the adapter handles D1 read replication and bookmark helpers.

<Callout type="info" title="Recommended Durable Objects path">
Start with `drizzle-orm/d1-object` for SQL-backed Durable Objects. The older `drizzle-orm/durable-sqlite` driver is still available for existing low-level Durable Objects SQLite applications and is covered later on this page.
</Callout>

#### Step 1 - Install packages

<Npm>
drizzle-orm
-D drizzle-kit wrangler
</Npm>

#### Step 2 - Define your schema

Use Drizzle's SQLite schema definitions.

```typescript copy filename="src/schema.ts"
import { sql } from 'drizzle-orm';
import { integer, sqliteTable, text } from 'drizzle-orm/sqlite-core';

export const messages = sqliteTable('messages', {
  id: integer('id').primaryKey({ autoIncrement: true }),
  roomId: text('room_id').notNull(),
  body: text('body').notNull(),
  createdAt: text('created_at').notNull().default(sql`CURRENT_TIMESTAMP`),
});
```

#### Step 3 - Configure the Durable Object

```toml copy filename="wrangler.toml"
name = "durable-object-drizzle-app"
main = "src/index.ts"
compatibility_date = "2026-06-13"

[exports.ChatRoom]
type = "durable_object"
storage = "sqlite"
```

#### Step 4 - Use Drizzle inside the Durable Object

Create the Drizzle client from `this.ctx` inside the Durable Object. Use primary-only routing for methods that write, and pass bookmarks back to callers when later reads need to observe those writes.

```typescript copy filename="src/index.ts"
import { desc, eq } from 'drizzle-orm';
import { DrizzleD1Object, drizzle } from 'drizzle-orm/d1-object';
import { messages } from './schema';
import * as schema from './schema';

type CreateMessageInput = {
  roomId: string;
  body: string;
};

export interface Env {
  ChatRoom: DurableObjectNamespace<ChatRoom>;
}

export class ChatRoom extends DrizzleD1Object<Env> {
  db = drizzle(this.ctx, { schema });

  async createMessage(input: CreateMessageInput) {
    const message = this.db.insert(messages).values(input).returning().get();

    return {
      message,
      bookmark: await this.db.d1.getCurrentBookmark(),
    };
  }

  async listMessages(roomId: string, bookmark: string | null = null) {
    await this.db.d1.waitForBookmark(bookmark);

    const rows = this.db
      .select()
      .from(messages)
      .where(eq(messages.roomId, roomId))
      .orderBy(desc(messages.id))
      .limit(50)
      .all();

    return {
      messages: rows,
      bookmark: await this.db.d1.getCurrentBookmark(),
    };
  }
}

export default {
  async fetch(request, env): Promise<Response> {
    const url = new URL(request.url);
    const roomId = url.searchParams.get('roomId') ?? 'general';
    const objectName = `room:${roomId}`;

    if (request.method === 'POST' && url.pathname === '/messages') {
      const room = env.ChatRoom.getByName(objectName, {
        routingMode: 'primary-only',
      });
      const input = (await request.json()) as CreateMessageInput;
      const result = await room.createMessage({ ...input, roomId });

      return Response.json(result.message, {
        status: 201,
        headers: { 'x-d1-bookmark': result.bookmark },
      });
    }

    if (request.method === 'GET' && url.pathname === '/messages') {
      const room = env.ChatRoom.getByName(objectName);
      const result = await room.listMessages(
        roomId,
        request.headers.get('x-d1-bookmark'),
      );

      return Response.json(result.messages, {
        headers: { 'x-d1-bookmark': result.bookmark },
      });
    }

    return new Response('Not found', { status: 404 });
  },
} satisfies ExportedHandler<Env>;
```

#### Step 5 - Configure Drizzle Kit

Use `driver: "d1-object"` so Drizzle Kit generates bundled SQLite migrations for your Durable Object.

```typescript copy filename="drizzle.config.ts"
import { defineConfig } from 'drizzle-kit';

export default defineConfig({
  schema: './src/schema.ts',
  dialect: 'sqlite',
  driver: 'd1-object',
  out: './drizzle',
});
```

Generate migrations:

```bash copy
npx drizzle-kit generate
```

#### Step 6 - Apply migrations from the object

SQL migrations must run inside the Durable Object that owns the database. Add a primary-only object method that calls `applyDrizzleMigrations()`.

```typescript copy filename="src/index.ts"
import migrations from '../drizzle/migrations';

export class ChatRoom extends DrizzleD1Object<Env> {
  db = drizzle(this.ctx, { schema });

  applyMigrations() {
    return this.applyDrizzleMigrations(migrations);
  }
}
```

Call that method through a primary-only stub:

```typescript copy
const room = env.ChatRoom.getByName('room:general', {
  routingMode: 'primary-only',
});

await room.applyMigrations();
```

#### Older `durable-sqlite` driver

Use `drizzle-orm/durable-sqlite` only for existing low-level Durable Objects SQLite applications that are not using the D1 object adapter.

```typescript copy filename="src/index.ts"
import { drizzle, type DrizzleSqliteDODatabase } from 'drizzle-orm/durable-sqlite';
import { migrate } from 'drizzle-orm/durable-sqlite/migrator';
import { DurableObject } from 'cloudflare:workers';
import migrations from '../drizzle/migrations';
import { messages } from './schema';

export class LegacyChatRoom extends DurableObject {
  db: DrizzleSqliteDODatabase;

  constructor(ctx: DurableObjectState, env: Env) {
    super(ctx, env);
    this.db = drizzle(ctx.storage, { logger: false });
  }

  async listMessages() {
    return this.db.select().from(messages);
  }

  async migrate() {
    migrate(this.db, migrations);
  }
}
```

```typescript copy filename="drizzle.config.ts"
import { defineConfig } from 'drizzle-kit';

export default defineConfig({
  out: './drizzle',
  schema: './src/schema.ts',
  dialect: 'sqlite',
  driver: 'durable-sqlite',
});
```

The older `durable-sqlite` driver does not provide the D1 object adapter's read replication setup, bookmark helpers, or primary migration forwarding.
